## 3. Phase 0 — Genspark-level reference slides (`ae8f91e`)

`docs/eval/genspark-ref/` (README + two XML decks)

Goal: find out which parts of the Genspark deck's polish POM 10.3.0 can produce
**before** building code-drawn chrome / recipes (Phases 1–3). Three XTSY slides
(brief: `tests/cases/gate-deck-xtsy-qcomm.yaml`) were written by hand, no LLM:

| Slide | What it tests |
|---|---|
| 1 Cover | radial-gradient background, 54px two-tone headline, `Layer` diagram (shapes + lines), mono kicker, `01 / 08` footer |
| 7 Impact | card micro-labels, italic last word in title, three card fills, `Icon arrow-up` per card, hero number tile |
| 8 Roadmap | month cards with `borderTop` accent, `MONTH 01 · DAY 1–30` labels, dark highlight card, closing statement |

- Two font variants: `genspark-ref-segoe.xml` (Segoe UI + Consolas) and
  `genspark-ref-gfonts.xml` (Space Grotesk + JetBrains Mono).
- Content uses brief text only, plus wording derived from it (the count "7",
  day ranges from "90 days / 3 months").
- Labels are 10–12px on purpose (house-style floor is 14) to test whether a
  smaller label tier reads well.
- First-compile finding: `line.width="0"` is rejected (`ZERO_STROKE_REMOVED`).
  Fix: fill-only shapes carry no `line.*` attributes at all.
- **Render results still pending** (to be run on the test PC with
  `python -m scripts.render_check --in docs/eval/genspark-ref --out output/render_check/genspark-ref`).
