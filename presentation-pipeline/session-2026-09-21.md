## 2. Visual Critic — Trigger and Strategy Criteria

### When repair runs at all
`critic_node` sets `passed = not any(i["severity"] == "high" for i in issues)`. Graph routes to `visual_repairer_node` only when `passed=False`.

### Patch vs Regenerate in `visual_repairer_node`
Reads `hints["strategy"]` directly from the visual critic LLM output:
- `"regenerate"` → `_do_regenerate()` — replan + fresh XML (3 LLM calls)
- `"patch"` / `"none"` → `_do_patch()` — fix in place (1 LLM call)

### Patch vs Regenerate in compile `repairer_node`
`visual_layout_broken` requires **both**:
```python
hints.get("strategy") == "regenerate" and hints.get("assessment") == "layout_broken"
```
`needs_tuning` + `regenerate` does NOT trigger REGENERATE in the compile loop.
